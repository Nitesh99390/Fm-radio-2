03 / Good to know

A little clarity.

The answers you need before you hit download.

Visit project support
What is an APK, and which devices can use it?

An APK is an Android application package. You can install it on a compatible Android phone or tablet; it won't install directly on iPhone or iPad. The developer hasn't provided a minimum Android version on this page, so compatibility isn't guaranteed.

Which download source should I choose?

Start with GitHub: it links directly to the APK over HTTPS. GoFile is an alternative hosting page. The direct server uses unencrypted HTTP, so prefer an HTTPS source when possible. Source availability and file contents have not been independently verified.

Why does Android ask to allow unknown apps?

Android asks for permission when installing an app outside an app store. Only allow the specific browser or file manager you're using if you trust the source. Review any security warnings, keep Play Protect enabled, and revoke this permission afterward.

What if a download or installation doesn't work?

Try another download source, check your connection and available storage, and confirm the file downloaded completely. If Android reports an incompatible package or a security issue, don't bypass the warning. Check the project's release page (opens in a new tab) or contact the developer for help.

Do I need an account to download?

This website doesn't require an account and doesn't collect sign-up details. External hosting services may have their own requirements and privacy policies. Account requirements inside the Android app are separate from this download page.
